## TH-DC-025 标签返回

- **Legacy 映射**：040 `tab-return`；controller `cover-return`；章节角色 `Browser-state Teach`。
- **第一屏与异常**：右边缘只露半张回转纸票；直接抓取会向外躲，停留时纸票反而略微回到页面。纸票切口与此前“纸层/遮挡”语法一致，旁边可拉出的盖页是关内后备。
- **合理假设**：A 更快抓住纸票；B 从另一侧拖入；C 让页面经历一次不可见再可见，纸票会完整返回。
- **推理链**：抓取导致逃离 → 停止追逐看到回弹 → 识别纸票属于“离开/返回”而非位置问题 → 真实切页再回或用关内盖页完成一次 hidden→visible。
- **负例反馈**：连续抓取只让纸票离开得更远但会在停手后复位；第一次页面加载不计返回；盖页未完全覆盖时只显示半张纸票，不误解锁。
- **解法与宽容**：发现后 30 秒内完成一次真实 visibility 循环；若 API 不稳定/测试环境禁用，则拉盖页完全遮住再揭开，二者同一语义。
- **提示**：H0 停止追逐时纸票回弹；H1 盖页把手边缘显一次；H2“它需要的不是被抓住，而是被重新看见”；H3“切到别处再回来，或用盖页完全盖住后揭开”。
- **空间反馈**：页面隐藏时渲染循环暂停；返回后的第一帧纸票从页面后层完整滑回，不持续动画；armed 时纸票嵌入计时卡侧边成为回转铰链。
- **输入等价**：键盘可聚焦盖页并用 Space 盖/揭；不强迫真实切标签。reduced-motion 用两帧可见状态切换。
- **验收**：首次 visibility 不误过；切页不丢谜题进度；不监听浏览历史或采集标签信息；后备路径可完成；已知答案 12 秒内完成。

## TH-DC-026 反向刻度

- **Legacy 映射**：061 `reverse-sweep`；controller `shared-control`；章节角色 `Mapping Twist`。
- **第一屏与异常**：云影覆盖一把方向反写的纸尺；扫描把手向右时云影向左走。尺上只有一个无刻度位，云影也只有一个缺口，但初始不在同一侧。
- **合理假设**：A 顺着缺口方向拖；B 把纸尺翻正；C 接受反向映射，利用相反运动把云影缺口送到无刻度位。
- **推理链**：小幅试探确认手与云影反向 → 尝试翻尺发现其方向锁定 → 比较云缺口和无刻度位的世界坐标 → 反向拖把手完成对齐。
- **负例反馈**：顺向直觉拖动会让目标误差连续扩大；翻纸尺只露出同样反写的背面；每次移动都显示缺口与无刻度位之间的距离变化，不给箭头答案。
- **解法与宽容**：拖扫描把手，使云影缺口覆盖无刻度位；目标区 44px，累计距离不参与判定。
- **提示**：H0 首次小拖明确显示反向关系；H1 纸尺无刻度位压一次；H2“控制方向已经被改写，但目标没有”；H3“向目标的反方向拖把手，让云缺口到无刻度处”。
- **空间反馈**：把手位于前层、云影在后层反向滑动，两者以短力杆连接；armed 时反向力杆折叠成稳定刻度环。
- **输入等价**：方向键控制把手且云影反向；reduced-motion 取消惯性，保留离散位置和误差变化。
- **验收**：固定拖动距离、方向密码或快速来回不能过；目标关系始终可见；已知答案 8 秒内完成。

## TH-DC-027 影子指的档案路

- **Legacy 映射**：065 `long-archive-route`；controller `focus-route`；章节角色 `Dynamic inference`。
- **第一屏与异常**：五枚档案标签的文字会在每次重来后变化，只有投向下一枚的三角影保持结构稳定；地图无编号，存在唯一无入边起点与无出边终点。
- **合理假设**：A 记住文字顺序；B 按位置或颜色走；C 把影子当有向边，每局现场推导一条无环路线。
- **推理链**：聚焦标签看到文字改变但影向稳定 → 比较所有入边找起点 → 逐段跟随影向并验证不会回环 → 到达唯一终点。
- **负例反馈**：按文字记忆路线在下一局首步即出现矛盾；走入已有入边节点时影子形成回环压痕；错误一步只回到最近分叉，不重排布局。
- **解法与宽容**：通过 focus/拖影/键盘站点沿五节点有向图走完；布局可从一组已验证可解模板中变化，不随机生成未知图。
- **提示**：H0 聚焦时只强化当前节点的三角影；H1 唯一无入边节点的纸面轻抬，不画路线；H2“会变化的是名字，不会变化的是方向”；H3“从没有影子指向它的标签开始，沿影子走到没有出向影的标签”。
- **空间反馈**：节点在不同深度形成档案塔，影子跨层投射；正确路线逐段把塔层对齐；armed 时五层压成一条纵深时间通道。
- **输入等价**：移动端按住空白拖影；键盘在邻接节点间移动；屏幕阅读器可查询当前节点的影子方向和入边数量。
- **验收**：固定序列不能跨布局通过；每个模板均有唯一可推路线；已知答案/看清布局后 25 秒内完成；不记录逐帧路径。

## TH-DC-028 滚轮回声

- **Legacy 映射**：067 `wheel-echo`；controller `wheel-echo`；章节角色 `Input echo`。
- **第一屏与异常**：纸轮缺一段半透明弧；滚动产生的实体波纹材质不匹配并先离开，约 120ms 后有一段半透明回声反向返回。
- **合理假设**：A 用实体波纹填缺口；B 反向滚动直接对齐；C 有效对象是延迟回声，需要把输入方向、实体结果和反向回声区分开。
- **推理链**：局部滚动观察实体波纹 → 发现实体即使对齐也被缺口排斥 → 等到反向半透明回声 → 用输入方向控制回声落入缺弧。
- **负例反馈**：实体波纹进入缺口时材质相斥；连续高速滚动让多个回声互相抵消，提示需要观察而非暴力；正确回声接近时缺口透明度匹配。
- **解法与宽容**：在谜题局部滚动/垂直滑动一次或少量几次，使反向回声进入 48px 缺弧区；页面全局滚动保持正常。
- **提示**：H0 延迟回声清楚可见；H1 半透明缺弧边缘回应一次；H2“最先出现的不是要留下的”；H3“观察滚动后的反向回声，让它填入半透明缺弧”。
- **空间反馈**：实体波纹在前层离开，回声从后层返回；armed 时回声与缺弧锁成一枚双向纸轮；running 不再响应滚轮改变规则。
- **输入等价**：触控在专用局部区域垂直滑；键盘上下键产生同样实体/回声。reduced-motion 用两个离散位置和 120ms 状态切换，不做拖尾。
- **验收**：不全局禁滚、不劫持页面；实体波纹不能过；高速滚动不能通过累计值；已知答案 8 秒内完成。

## TH-DC-029 档案八字

- **Legacy 映射**：069 `archive-figure-eight`；controller `trace`；章节角色 `Topology Mastery`。
- **第一屏与异常**：左右泪滴形档案章各缺一段，共享中央交叉压痕；视觉上可以画两个圆、外轮廓或八字，只有拓扑关系决定结果。
- **合理假设**：A 分别画两个闭圆；B 沿外轮廓一圈；C 一笔形成两个闭合瓣，并从不同方向两次穿越同一中心。
- **推理链**：分开圆看到中心没有共享墨 → 外轮廓看到只有一个闭域 → 观察中央双向压痕 → 一笔双瓣、自交、回到起点。
- **负例反馈**：两个分开圆各自成章但中心断开；外轮廓闭合后内部仍有两个缺墨瓣；中心摩擦不会累计成穿越，必须从不同方向进入/离开。
- **解法与宽容**：同一连续轨迹形成左右两个闭合瓣，至少两次不同方向穿过中心，终点回到起点 40px 范围；使用拓扑段判定而非像素模板。
- **提示**：H0 中央压痕对两侧同时回应；H1 中心交叉只压一次；H2“重要的不是画得像，而是一笔怎样穿过中心”；H3“画一个连续八字：左右各闭合，并两次穿过中央”。
- **空间反馈**：轨迹墨线在每次穿越中心时交替上/下层，形成真正的空间交叉；armed 时双瓣抬起成为立体双环。
- **输入等价**：指针/触控连续轨迹；键盘按可访问的八个方向节点构成两瓣，仍需共享中心；不要求手写精度。
- **验收**：两个圆、中心摩擦、累计距离均不能过；轨迹容差两次尝试内目标 ≥90%；不保存输入轨迹。

## TH-DC-030 重来后留下的影子

- **Legacy 映射**：084 `ghost-session`；controller `cover-return`；章节角色 `State memory Master`。
- **第一屏与异常**：纸点没有完整匹配槽，只有两个互补半圆压痕；普通“再来一次”仍是正式功能。移动纸点后留下浅影，而本关重置会复位纸点却不清掉该浅影。
- **合理假设**：A 找隐藏完整圆槽；B 把纸点在两半圆间快速移动；C 利用重置保留世界记忆，让两次位置跨会话合成一圆。
- **推理链**：拖到任一有依据半圆看到浅影 → 移开确认影子保留但单局无法同时占两处 → 使用重置看到纸点复位、影子仍在 → 第二次放到互补半圆。
- **负例反馈**：无依据位置留下的影子形状不吻合且重置后淡出；快速来回只移动当前纸点，不复制；错误第二位置显示两影无法闭圆并允许立即调整。
- **解法与宽容**：先将纸点放入任一半圆压痕，执行一次本关重置，再放入互补压痕；退出关卡时清理临时影子。
- **提示**：H0 移动后影子可见；H1 “再来一次”附近不加文字，只让旧影保持一次；H2“这次重来没有清除所有东西”；H3“先在一个半圆留下影子，重来，再把纸点放到另一半”。
- **空间反馈**：旧影位于历史层、当前纸点位于现在层；重置时只有现在层回到起点；armed 时两层合为完整时间圆，证明记忆跨状态而非复制物体。
- **输入等价**：重置继续使用现有语义按钮与测试 ID；键盘拖放等价。reduced-motion 用历史层透明度表示保留。
- **验收**：不改变全局重试/失败逻辑；只需一次重置；无依据随便放置不能穷举过；离开关卡无残留；已知答案 15 秒内完成。

## TH-DC-031 菜单缺口里的日食

- **Legacy 映射**：086 `eclipse-session`；controller `shared-control`；章节角色 `Function-layer Compose`。
- **第一屏与异常**：右上是真实可用菜单；展开的菜单纸有圆形缺口，与场景太阳大小相近。菜单可以从非控件纸边拖动，但菜单项仍保持可点击。
- **合理假设**：A 菜单中有隐藏开关；B 点击太阳；C 把功能纸层当遮挡物，用缺口套太阳后关闭，让圆影落到小数点。
- **推理链**：检查菜单项确认都是正常设置 → 观察缺口与太阳互补 → 拖菜单纸产生日食 → 关闭菜单，缺口的圆影在页面层留下并对准数字小数点。
- **负例反馈**：仅开关菜单不前进；拖到其他圆形装饰只产生普通遮挡；套太阳但不关闭时日食成立、圆影尚未转移，明确最后因果。
- **解法与宽容**：从菜单非控件边缘拖纸层，使缺口包住太阳（容差 20%），再正常关闭菜单；真实设置项不被拖动拦截。
- **提示**：H0 菜单缺口与太阳有相同边缘折射；H1 菜单纸的可拖边缘轻压一次；H2“菜单不只装着功能，它本身也是一张纸”；H3“用菜单缺口套住太阳，再关闭菜单留下圆影”。
- **空间反馈**：菜单处于明确前景层，太阳在背景层，日食形成贯穿孔；关闭后圆影沿 Z 轴落到数字小数点但不遮盖数字；armed 时小数点成为时间核心轴心。
- **输入等价**：键盘打开菜单后选择“移动纸层”句柄，用方向键定位，再 Esc 关闭；屏幕阅读器保持菜单语义和焦点管理。
- **验收**：不隐藏/更名真实设置；菜单项触控不触发拖动；开关菜单本身不能过；已知答案 15 秒内完成。

## TH-DC-032 两种宽度的一条线

- **Legacy 映射**：089 `device-braid`；controller `resize`；章节角色 `Responsive Compose`。
- **第一屏与异常**：关内纸质小视口有可调宽度；窄版显示点状丝带从上方经过中央纸夹，宽版显示连续丝带从左侧经过。两种不是两个设备，而是同一内容的响应式重排。
- **合理假设**：A 改真实浏览器宽度；B 在单一宽度直接接线；C 先在窄版夹住一种状态，让它留下关系，再展开为宽版与另一状态编织。
- **推理链**：调小视口确认内容重排而非缩放 → 发现中央纸夹可保留窄版痕迹 → 在窄版夹住点状丝带 → 展开宽版，让连续丝带从其下方经过。
- **负例反馈**：真实窗口变化不进入谜题判定；未夹住就展开时窄版痕迹消失；层序反了会形成可见错误编织而非位置成功。
- **解法与宽容**：拖关内视口边缘进入窄区，夹住点带，再展开至宽区；最终需窄版在上、宽版在下的一次交叉关系。
- **提示**：H0 小视口宽度变化改写布局；H1 中央纸夹在窄版时压一次；H2“先保留一个宽度里的关系，再去另一个宽度”；H3“窄版夹住点带，再展开，让宽版连续带从下方穿过”。
- **空间反馈**：小视口不是 3D 模型，而是一张可伸缩纸窗；被夹痕迹留在历史层，新布局在当前层；armed 时两层编成响应式时间织带。
- **输入等价**：独立单指/鼠标边缘抓手；键盘用窄/宽离散档位和纸夹按钮；不依赖双指或真实设备旋转。
- **验收**：真实窗口、浏览器缩放、语言和设备切换不能过；窄宽阈值在 360/390/平板上都可达；所有关键部分可正常滚动显示；已知答案 25 秒内完成。

## TH-DC-033 把六拍折成一拍

- **Legacy 映射**：093 `six-beat-lock`；controller `fold`；章节角色 `Temporal compression`。
- **第一屏与异常**：六段纸带长短相间，看似节拍谱；每段中点都有折线，直接敲节奏没有世界反馈。长段恰能包住两个短段，是此前“时间长度=空间长度”和“纸背”语法的组合。
- **合理假设**：A 按六段长短敲节奏；B 把六端顺序连接；C 沿折线物理压缩时间距离，让六个端点在空间上成为同一拍。
- **推理链**：敲击无反馈排除演奏 → 比较长短与折线位置 → 试折一段看到多个端点趋同 → 以任意合法折序让全部端点重合。
- **负例反馈**：错误折向使端点分组但不能全部重合；正确部分折叠会保留为厚纸层；无需按唯一顺序重做。
- **解法与宽容**：沿可见折线折叠六段，最终六端进入同一宽松区域；折序可交换，判定最终关系而非动作脚本。
- **提示**：H0 折线和长包短关系可见；H1 六个端点依次压出同心影；H2“这一关不是演奏六拍，而是缩短它们之间的距离”；H3“沿折线折纸，让六个端点压在同一个位置”。
- **空间反馈**：每次折叠增加真实纸层厚度，时间段沿 Z 轴压缩；armed 时六层形成一枚厚实单拍印章；success 印章落下但不遮挡结果。
- **输入等价**：触控拖折角或键盘逐折线切换方向；reduced-motion 使用静态折前/折后状态。
- **验收**：六次点击不能过；没有唯一强制折序；已知答案 25 秒内完成；手机下折叠对象不被计时卡截断。

## TH-DC-034 三相叠成一个现在

- **Legacy 映射**：095 `triple-phase`；controller `layer-stack`；章节角色 `Temporal order`。
- **第一屏与异常**：过去、现在、未来三张半透明时间片显示同一圆环的不同缺口；三者叠放可补圆，但错误层序产生方向相反的重影。纸边有因果先后压痕，不依赖文字标签。
- **合理假设**：A 只要三片重叠即可；B 按颜色深浅排序；C 同时满足缺口互补和时间前后层级，过去在下、现在居中、未来在上。
- **推理链**：叠合位置得到圆形但仍有重影 → 观察重影方向随层序变化 → 读取纸边先后压痕 → 调整层序，得到无重影的完整现在。
- **负例反馈**：位置正确/层序错误时明确显示完整圆 + 时间重影，证明缺的是第二条件；只按颜色排序时纸边因果箭头断裂；正确相邻关系逐对锁定。
- **解法与宽容**：三片中心对齐且层序为过去→现在→未来；位置吸附与层序控制分离，避免精细拖动。
- **提示**：H0 错层序产生方向性重影；H1 三片纸边的先后压痕依序显色；H2“完整形状还不够，时间也有前后”；H3“过去放底层、现在居中、未来放上层并对齐”。
- **空间反馈**：三片沿 Z 轴形成真正时间层；armed 时它们收束到同一焦平面，圆环完整但仍可看见纸层厚度；running 从未来层向现在层收紧，不篡改时间值。
- **输入等价**：键盘可分别移动位置和层序；屏幕阅读器报告相邻先后关系。reduced-motion 保留重影方向和静态层间距。
- **验收**：仅重叠、仅排序或按颜色不能过；与早期 008 的差异必须可见——本关有顺序与重影推理；已知答案 15 秒内完成。

- **Legacy 映射**：099 `relay-polyrhythm`；controller `wave-align`；章节角色 `Systems intersection`。
- **第一屏与异常**：二分纸波与三分纸波叠在同一水平线上，交点很多但只有一个共同六点周期；透明检查带有六个等距孔，延续关卡 016 的“消去相同信息”工具语法。

- **推理链**：点击节奏不改变系统 → 波峰对齐仍留下大量非交点 → 移动检查带发现它只保留两波共同穿孔处 → 整体对齐六个共同点。
- **负例反馈**：按 2/3/6 次只让对应波短暂加深；检查带错相时部分孔为空，显示具体不一致；对齐五孔时不因接近而误过，第六孔提供清楚差异。
- **解法与宽容**：水平移动整条检查带，使六孔同时覆盖两波交点；只判整体相位，不要求逐孔操作。
- **提示**：H0 检查带消隐非交点；H1 六孔按共同周期显一次；H2“不要分别追两种节奏，找它们同时成立的位置”；H3“整体移动六孔检查带，对准两条波的共同交点”。
- **空间反馈**：两波在前后层交叉，检查带位于中层；正确孔形成六根短光柱贯穿三层；armed 时六柱围成低密度空间计时环，避免视觉噪声。
- **输入等价**：水平拖带或左右键；颜色不是唯一编码，交点有形状/穿孔冗余。reduced-motion 使用静态交点和孔填充。
- **验收**：按次数、对齐单一波峰或逐孔穷举不能过；视觉密度不遮数字；已知答案 15 秒内完成。
