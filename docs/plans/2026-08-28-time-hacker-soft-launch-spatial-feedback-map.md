- `DESIGN_VARIANCE: 8`
- `MOTION_INTENSITY: 8`
- `VISUAL_DENSITY: 3`
- 体验模式：Experience。谜面与物体关系先于界面说明。
- 技术原型：语义 HTML 控件、CSS perspective、Canvas2D 时间场。Canvas 只读状态，`aria-hidden`、`pointer-events:none`。

## 3. 共同空间语法

### 3.1 时间场只表达状态

隔离原型的计时演示必须镜像当前正式辅助计时合同：未解锁时保持纯净计时；解锁后正常运行至 `9.50`，随后每个真实秒只前进 `0.10` 显示秒；`10.00` 连续保持 3 秒，之后仍以同一慢速离开。不得用连续 `0.1×` 插值穿过 `10.00`，也不得让视觉状态改变这条映射。

| 状态 | 空间反馈 | 行为边界 |
| --- | --- | --- |
| `idle` | 纸层保持可读的轻微呼吸，远近关系可见但不提示答案 | 不制造虚假可点击物，不持续吸引注意力 |
| `running` | 环带向数字收紧，景深略变浅，关卡物体保持清晰可操作 | 数字和停止按钮始终为语义 HTML，Canvas 不接收输入 |
| `stopped` | 判定提交后冻结上一帧空间关系 | 不预测成功与失败，不延迟停止请求 |
| `success` | 关卡完成几何锁定，短促折射或涟漪释放 | 不阻塞下一关，禁止重复物件或接缝漂移 |
| `miss` | 整体克制回弹，主按钮立即可重试 | 不增加惩罚、等待或新动画门 |

### 3.2 提示纪律

- 初始不显示作弊方式、操作步骤、目的地虚线框或答案名称。
- 第一级提示只指向异常关系，例如“它似乎会回应你的动作”。
- 第二级提示指出因果类别，例如“也许少做一点会看到更多”。
- 第三级提示才允许接近操作方法，但仍不自动执行。
- 提示由既有提示系统和时间门控制；空间层不得自行发出答案文案或把目标做成高亮热区。

### 3.3 响应式与减少动态

- 桌面以完整纸上舞台展示深度，保持秒表、主按钮、谜题对象的清晰层级。
- `360×800`、`390×844` 和 `590×698` 短视口使用自然纵向滚动，不缩小关键机关，不建立内部滚动层。
- 移动端降低 Canvas DPR 与元素数量，禁用指针视差，必要时退化为静态 CSS 2.5D。
- `prefers-reduced-motion: reduce` 停止循环、视差、漂移与空间旋转，保留完成几何、文字、状态和结果。

## 4. 冻结 12 关空间反馈地图

### 01 / 001 `four-corner-breach`

- 真实规则：拖动游离纸角到破损页框缺口；单击无效，键盘方向键等价。
- 空间隐喻：整页纸框拥有真实厚度，缺角是从同一纸体剥离的折片，不是背景装饰。
- 状态：idle 缺口漏光；running 框厚随时间收紧；success 折角被纸框吸收且不留副本；miss 仅纸框轻微回弹。
- 风险与验收：Canvas 不得参与吸附；完成后游离折角数量为 0；手机拖动不触发页面滚动。

### 02 / 002 `breath-gap`

- 真实规则：有意义输入会重置安静窗口；静置 2.5 秒后气泡出现，长按 1.2 秒完成，提前松开可立即重试。
- 空间隐喻：两片纸叶像薄膜肺叶，安静时从压扁状态恢复体积，气泡从纸缝深处浮到可操作层。
- 状态：idle 先升温后扩张；running 只让外围时间场收紧，不打断气泡；success 气泡成为稳定透镜；miss 不关闭已发现气泡。
- 风险与验收：普通鼠标移动不算打扰；后台时间不计入 2.5 秒；Space 与长按等价；减少动态用离散开合状态。

### 03 / 003 `slow-command`

- 真实规则：四块 `FAST` 字牌分别通过点击、竖向轻扫、滚轮或上下键翻动，组成 `SLOW` 并稳定 400ms。
- 空间隐喻：每块字牌是一枚有厚度的活版字模，错误字母漂在快速前景，正确字母落入同一慢速焦平面。
- 状态：idle 字模错层；running 时间场从四列间穿过但数字不折射；success 四块字模压印同一长影；miss 字模不回到初值。
- 风险与验收：不出现输入框、提交按钮或软键盘；机械每列翻一次不能误通关；中文提示只在渐进提示中解释词义。

### 04 / 008 `relay-sandwich`

- 真实规则：先把透明薄片置中，再让左右珊瑚外壳从两侧合上；外壳先放会弹回，正确一侧保留锁定。
- 空间隐喻：三件物体拥有真实 z 层级，透明片折射后层，两壳互补半圆在共享中心闭合。
- 状态：idle 三层分散悬浮；running 时间环穿过透明中层；success 三层锁成一枚完整圆芯；miss 只弹回当前错误上层。
- 风险与验收：不能退化为“三件都拖到同一虚线框”；完成时中心误差不超过 1px；遮挡后仍可理解层级与键盘焦点。

### 05 / 014 `corner-cross`

- 真实规则：拖动一条丝带会让另一条以 35% 镜像响应；两个切口同时进入共享中心才完成。
- 空间隐喻：横纵丝带处在不同深度，却共享同一中央压痕；一条的张力通过纸下连杆传到另一条。
- 状态：idle 交点缺失；running 张力线向中心汇聚；success 双轴磁吸成十字；miss 保留已发现的联动关系。
- 风险与验收：单轴对齐不能过关；单指和键盘均可完成；不要求双指精调。

### 06 / 024 `precision-five`

- 真实规则：先从尾点连续描过五点，再按短、长、短、长间隔敲出五拍；五次等间隔无效。
- 空间隐喻：曲线是一条有高度差的纸轨，墨珠以恒速穿越不同路程，路程本身就是节拍谱。
- 状态：idle 墨珠显示路径差；running 每个有效拍点把墨珠锁到下一层；success 五点形成一条空间节拍梁；miss 曲线段回缩并可马上重试。
- 风险与验收：声音不是必要信息；全局滚动不被接管；键盘路线为方向键完成轨迹、Space 打拍；不做 Simon 记忆。

### 07 / 035 `horizon-shift`

- 真实规则：拖动背景暴露前后层视差，让太阳与两条地平线进入同一高度区；设备倾斜仅为自愿增强。
- 空间隐喻：纸上天空明确分为前景、远景、倒影三层，视差是谜面而不是装饰相机。
- 状态：idle 高度关系近似但不重合；running 三层以不同速率收紧；success 三层共享一条地平线；miss 不改变视角位置。
- 风险与验收：页面滚动不抢拖景；权限拒绝仍完整可玩；移动端不用持续设备传感器作为必经路线。

### 08 / 044 `focus-orbit`

- 真实规则：移动透明焦点片到秒表小数点周围，使三层错位残影合线；轨道本体不可拖动解锁。
- 空间隐喻：透镜是可移动观察层，轨道处于不同焦平面；玩家移动观察者而非被观察物。
- 状态：idle 三层残影；running 焦深逐渐变浅；success 透镜、轨道、小数点共享光轴；miss 只在错误对象上产生波纹。
- 风险与验收：不能成为不可见热区；透镜必须有可见边缘与局部清晰效果；方向键等价。

### 09 / 067 `wheel-echo`

- 真实规则：在谜题区域滚动、短滑或用上下键；实体波纹离开后，约 120ms 的反向半透明回声填入缺弧。
- 空间隐喻：实体波纹在前景纸轮上滚走，回声从背层反向翻回，材质差异决定哪个能填缺口。
- 状态：idle 缺弧与双波纹错层；running 回声频率随时间场收紧；success 半透明回声嵌入缺弧；miss 实体波纹散开。
- 风险与验收：只接管谜题区域，不禁用全页滚动；不使用固定方向序列；减少动态保留前后材质与最终嵌合。

### 10 / 040 `tab-return`

- 真实规则：发现半票后经历真实 hidden 到 visible，或用等价盖页路线完全盖住再揭开，纸票才返回。
- 空间隐喻：纸票跨越页面边界与浏览器可见性平面；离开不是剧情切场，而是谜面的一层。
- 状态：idle 半票卡在边界；running 边界厚度随时间变化；success 纸票从背层回到压痕；miss 保留发现进度。
- 风险与验收：未发现就切页不能误计；切页不丢进度；真实路线不稳定时盖页路线仍完整正式。

### 11 / 069 `archive-figure-eight`

- 真实规则：一笔完成左右闭合瓣，从不同方向两次穿过共享中心，再回到起点附近；两个分开圆无效。
- 空间隐喻：两枚档案章处于两个薄纸平面，笔迹在中心穿层两次，拓扑关系比标准数字外形重要。
- 状态：idle 双瓣缺墨；running 已完成瓣保留空间墨迹；success 两层章在交点压合；miss 只让断口褪色。
- 风险与验收：不能按累计距离或像素模板过关；单指、鼠标和键盘轨道等价；断笔不清空已理解关系。

### 12 / 100 `silent-constellation`

- 真实规则：收拢两组星群显出 V 负空间，再用页面轨迹或键盘表达 V；摄像头手势只能在主动同意后作为可选彩蛋。
- 空间隐喻：六星是边界，真正对象是它们之间的负空间；明亮暮色仍属于纸上剧场，不转黑色科技风。
- 状态：idle 星群分层；running 负空间逐渐获得体积；success V 形星光从空白中升起；miss 星群回弹但不遮挡重试。
- 风险与验收：resize 与缩放不能过关；页面路线排第一；摄像头超时、拒绝或失败立即关闭 tracks 并回到页面路线。

## 5. 第一批隔离交互原型

选择 `002 / 003 / 008 / 024`，因为它们覆盖四种不同的因果结构：

1. `002` 验证“不操作也是操作”能否通过纸膜体积和气泡深度被感知。
2. `003` 验证动势字体能否成为真实机关，而不是背景文字动画。
3. `008` 验证网页级 3D 是否能直接解释材质层级与组装顺序。
4. `024` 验证时间和空间能否通过路径长度与节拍共同表达。

隔离入口：`soft-launch-spatial-lab.html?level=002`，并支持 `003`、`008`、`024`。

原型只模拟关卡发现、破解和五种视觉状态。它不导入正式游戏模块，不调用计时、判定、进度、API、数据库或分析。

## 6. 第一批可观察验收

- 四关初始页面没有答案文案、步骤列表、目标虚线框或发光入口。
- 四关各自保留正式输入因果，不能通过同一种拖拽行为全部完成。
- `002` 通过静置和长按；`003` 通过逐字牌翻动；`008` 通过中层先行的 z 层组装；`024` 通过连续轨迹和短长节拍。
- 桌面、`390×844`、`360×800`、`590×698` 均可到达全部交互对象，不发生横向溢出。
- 键盘路径可完成四关，焦点清晰，状态变化进入 live region。
- reduced-motion 下没有循环空间运动，关卡仍能完成，成功与失败不依赖颜色。
- Canvas 不进入无障碍树和焦点顺序，不拦截鼠标或触摸；页面隐藏时停止渲染。
- 视觉状态切换不改变已完成的关卡几何，也不重置玩家已经发现的关系。

### 6.1 交互坐标与生命周期细则

- `024` 的倾斜纸轨只是视觉平面。指针命中必须依据变换后可见点的屏幕空间包围盒，划痕绘制再通过 SVG CTM 反变换回 viewBox；禁止用倾斜后整体 `getBoundingClientRect()` 做线性百分比换算，否则可见点与逻辑点会漂移。
- `002` 的 1.2 秒长按必须是连续前台行为。窗口 `blur`、`document.hidden`、pointer cancel 或按键释放都立即取消本次按住，气泡保持可重试，不能在后台自行完成。
- `stopped` 后的 success/miss 视觉回调必须持有可取消 ID。重试、切关、重置和页面离开先清除旧回调，禁止旧结果污染新关卡状态。
- 评审工具的状态预览与真实计时状态分离。预览 `running` 时主操作按钮禁用并明确显示“状态预览”，不能出现按钮写着停止、实际点击却开始计时的矛盾。
- Canvas 的 visibility、reduced-motion、pagehide 和 pageshow 监听器使用可解绑的具名处理器。进入 BFCache 时暂停 RAF，恢复时重新测量并继续；非持久离开才完整销毁观察器和监听器。

## 7. 后续批准门

本轮原型通过只代表方向可继续评审，不授权修改正式游戏。用户确认第一批的 3D 强度、发现感、提示节奏与四种操作准确后，下一步才是：

1. 把认可的空间语法写入正式实施合同。
2. 为同机制族定义可复用视觉能力与专用控制器边界。
3. 在默认关闭的开关后，仅挑一到两关接正式只读状态。
4. 用相同输入序列证明视觉开关 on/off 的计时、判定、请求和匿名事件等价。

在该批准前，不修改正式页面、`src/game`、`src/components`、测试合同、数据库或部署配置。
