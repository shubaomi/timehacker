## 4. 22 种共享空间能力

共享的是渲染能力，不是解法。每关仍使用自己的正式控制器和专属几何。

| 控制器族 | 空间能力 | 推荐技术 | 禁止退化 |
| --- | --- | --- | --- |
| corner-repair | 纸体厚度、缺口、吸附缝 | HTML + CSS perspective | 统一拖入虚线框 |
| patient-hold | 压力体积、呼吸膜、相位冻结 | CSS + Canvas2D | 看见即长按、动画结束即通过 |
| word-shift | 活版字模、快慢焦平面 | CSS 3D type | 输入框或提交按钮 |
| shadow-sort | 实体层与固定投影层 | CSS + Canvas2D shadow | 按外形机械排序 |
| light-drag | 可移动光体与投影关系 | Canvas2D/WebGL 光学叶 | 移动物体代替光源 |
| trace | 跨层墨带、背面续线、自交拓扑 | SVG + CSS depth | 累计距离或像素模板 |
| frame-drag | 可移动视口、裁切体、框外连续空间 | HTML clip + CSS depth | 改成拖里面的对象 |
| layer-stack | 明确 z 层、遮挡、折射、夹层 | CSS 3D；必要时 WebGL 光学 | 所有物件拖到同一点 |
| fold | 正背面、铰链、纸厚、折痕 | CSS 3D transform | 单纯旋转图标 |
| coupled-drag | 共享轴、拉力、镜像连杆 | CSS variables + Motion values | 两个独立拖拽 |
| wave-align | 两张波面与干涉切口 | SVG/Canvas2D | 对准任意峰值 |
| flip | 正反材质与折痕证据 | CSS preserve-3d | 颜色翻牌游戏 |
| orbit | 轨道深度、尾迹、角间距 | Canvas2D + CSS ring | 累计旋转圈数 |
| resize | 可变边界、内外关系、重排 | HTML resize handle + CSS | 浏览器缩放作为唯一解 |
| focus-route | 清晰度在深度间传递 | HTML focus + CSS depth | 隐藏点击热区 |
| rhythm | 路程、相位和静默的空间节拍 | Canvas2D + Web Audio 可选反馈 | 毫秒反应考试 |
| wheel-echo | 前景实体波与背层回声 | Canvas2D | 接管全页滚动 |
| cover-return | 页面前后层、离开与返回 | HTML cover + visibility | 后台自动通关 |
| rotate | 共轴齿带、铅垂与角度档位 | CSS 3D + Motion values | 自由相机 |
| edge-route | 页面边缘穿越与连续表面 | CSS wrap + SVG | 隐形传送点 |
| shared-control | 一个原因驱动多个对象 | CSS variables/Canvas2D | 逐个修理 |
| constellation | 星体边界与负空间体积 | CSS/WebGL optical + HTML trace | 摄像头成为必选 |

技术记号：`P` 表示 HTML/CSS 透视；`C` 表示只读 Canvas2D 时间场；`W` 表示可选隔离 WebGL 光学材质；所有关卡必须有无循环运动的 `S` 静态降级。

## 5. 100 关逐关矩阵

状态缩写：`R` 为 running，`F` 为 stopped，`S` 为 success，`M` 为 miss。`F` 必须在正式停止判定提交之后冻结上一帧，不能预测结果。

## 7. 响应式、性能与无障碍

- `1440×900` 展示完整层深；`734×876`、`590×698`、`390×844`、`360×800` 保留自然纵向滚动，不裁切机关。
- 移动端 DPR 上限 `1.25`，桌面上限 `1.75`。视觉复杂度按粒子、光层、细分数下降，不缩小命中区和规则证据。
- reduced-motion 停止循环、视差、漂移和空间旋转，改用固定正背、层级、压痕、阴影及完成几何。
- Canvas/WebGL 均 `aria-hidden="true"`、不设置 `tabindex`、`pointer-events:none`，且永不进入焦点顺序。
- 页面隐藏、离屏、面板切换、关卡非活跃或 BFCache 进入时暂停 RAF；恢复后重新测量，不累计隐藏时间完成视觉仪式。
- HTML、CSS、SVG 路径承担输入与命中；WebGL 仅允许材质、折射、体积光和背景时间场。
