## 1. 实现裁决

- Legacy FULL/100、SOFT_LAUNCH/12、正式计时、判定、API、数据库、分析和进度保持只读。
- 002-036 不再把共享 `V2PuzzleScene` 的直接最终动作视作完整 Director 解谜。
- 每关先经过 Director 独立证据阶段，证据成立后才进入现有最终操作阶段。
- 证据阶段不能显示操作文案、答案箭头、虚线目标框或持续高亮；只用物体关系和玩家试探后的局部反馈。
- 错误试探立即、可逆、无等待，并必须排除一个合理假设。证据完成后不重复，不把难度变成体力劳动。
- 视觉层仍是状态单向消费者。Director 证据门只控制隔离原型自身的“可进入最终动作”状态，不接正式游戏 reducer、计时、判定或进度。

## 2. 共用运行时结构

```text
idle evidence field
  -> probe (two or three causal observations)
  -> evidence-complete (short spatial lock)
  -> existing Director final-action scene
  -> armed
  -> semantic HTML timer start / stop / result
```

- `H0`：前台 45 秒内没有提示入口，只有谜面和试探反馈。
- `H1`：玩家主动请求后仅改变相关观察区域的边缘/层差，不出现文字。
- `H2`：显示关系句。
- `H3`：显示完整动作句。
- 证据完成前，直接模仿最终动作不能解锁；证据完成后，已知答案执行维持原规格上限。
- Pointer、touch、keyboard 使用同一离散语义。连续拖动值不得进入 React state。
- reduced-motion 禁用漂移、弹簧和景深飞行，保留层序、形状、遮挡、对比和状态播报。

## 7. 可观察验收

- 002-036 每关在 Director 路径都有独立证据门，且直接操作旧最终场景不能绕过它。
- 每关至少两个 probe；013-036 至少三个有信息观察或两个依赖条件。
- 错误 probe 在 150ms 内改变局部状态，且不显示“点击/拖动某物”的答案句。
- 完成证据后只播放 220-480ms 的空间锁定，然后允许进入最终动作；不额外等待。
- 45 秒前不出现提示入口；H1 没有文字；H2/H3 与注册表冻结文案一致。
- 360×800、390×844、768px、1440px 下证据区、计时、主按钮和最终场景都可达且页面可滚动。
- 键盘可完成全部 evidence gate；触控目标至少 44px；焦点可见。
- reduced-motion 与关闭空间反馈时仍可通过形状、层级、对比和状态播报取得同一证据。
- 全量测试证明 Director 隔离路径行为；不宣称未知答案玩家难度、乐趣、留存或商业效果已经验证。
