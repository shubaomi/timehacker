## R100-051 墨迹开路 / Ink opens a path

- 前置与认知增量：前章规律；开关改变门，先绕行才能通过。
- 错误假设：眼前最接近目标的动作总是正确。。可逆反例：开关改变门，先绕行才能通过。允许暂时退回，比较下一步会开放或破坏的关系。
- 精确规则配置：

```json
{"kind":"route","rows":["S.a##",".#.##","..A.E","##..#","....."],"initial":[0,0],"finalMask":1}
```

- 输入/目标：方向控制墨点在纸上网格移动，#不能进入；a/b/c进入时切换同字母门，A/B/C仅对应位为1时可进入。S为起点，E为终点，位置和门位掩码同时满足才完成；不要求固定路线。
- 视觉：墨点、阻挡、开关和门在同一可读网格内；形状和字母区分状态，方向输入不靠页面滚动。手机不裁切，按钮44px；页面自然滚动，无固定互动遮挡。
- 提示梯度：H1比较一次操作影响；H2“开关改变门，先绕行才能通过。”；H3“开关改变门，先绕行才能通过。允许暂时退回，比较下一步会开放或破坏的关系。”。解答不自动执行。
- 状态：探索中反馈即时，失败保持状态、无惩罚；撤销恢复完整局面（包含门）；重置恢复initial；解开后锁定并进入原计时奖励，停表依旧手动。
- 验收：初始/一步不能完成；搜索验证存在路径；目标每个分量都检验；规则不随DOM/屏幕尺寸变化；完整组件按钮路径、撤销/重置、键盘与触摸同义。
